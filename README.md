# AIML College FAQ Chatbot

## Project Overview

The AIML College FAQ Chatbot is a simple rule-based chatbot developed using Artificial Intelligence Markup Language (AIML) and Python.

The chatbot can answer frequently asked questions related to college information such as college timings, library location, available courses, and other basic queries.

## Technologies Used

* Python
* AIML
* XML
* Command Prompt

## Features

* Answers predefined college-related questions
* Provides instant responses
* Simple rule-based conversation
* Easy to add new questions and answers
* Beginner-friendly chatbot project

## Example

User: Hello

Bot: Hello! Welcome to the College FAQ Bot. How can I help you?

User: What are the college timings?

Bot: The college is open from 9 AM to 5 PM, Monday to Friday.

User: Where is the library?

Bot: The library is located on the first floor of the main building.

## How to Run

1. Install Python.
2. Install the AIML package.
3. Download or clone this repository.
4. Open Command Prompt in the project folder.
5. Run:

```bash
py -3.11 bot.py
```
